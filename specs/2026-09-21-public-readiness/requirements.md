# Requirements

- Escape untrusted text for presentation, not delete technical syntax. Decode to
  the original visible operators, paths and commands; neutralize media directives.
- Protect licensing/prohibition/eligibility clauses and retain their context.
  Unknown semantic cases remain a disclosed limitation, not a completeness claim.
- Fixed official RSS sources, HTTPS/public-address/TLS checks, no redirects,
  bounded XML bytes/items, no DTD/entity declarations; reject source mismatch.
- Single-operator state directory, exclusive process lock, private permissions,
  durable reservations, no automatic retries or credential logging.
- Explicit network and inference switches. Maximum six article fetches and four
  local model attempts per edition. Collection is separately capped at the two
  registered feeds per invocation. Persist each reservation before transport.
- Save full supporting report and escaped preview before marking an edition ready.
- Separate send command binds approval to edition, content digest and fixed
  numeric destination. Model/source data cannot choose destination or credentials.
- Confirm provider message ID before consuming stories. Never retry ambiguous
  sends. Safe unsent cancellation retains history and does not reopen that day's
  budget; confirmed receipt reconciliation never sends a message.
- Public title/timezone configurable at initialization; preserve existing library
  defaults for the private integration. Scheduler example disabled by default.
- No new external Python dependencies; no automatic installation or activation.

### Post-acceptance preparation-context repair

Before the owner-authorized Git publication, repair the observed false hold for
`To prepare:`. Only use an exact, unique paragraph in the hash-verified full source;
retain every following complete paragraph through the next recognized heading or
source end. Bound the expanded passage to fit a reading paragraph. Missing,
ambiguous, truncated, nested or oversized context stays held. Other unfinished
restriction lists remain held. Do not change prompts, packets, historical outputs,
production state or model budgets. Verify the saved live responses offline and
report this separately from another live model-to-Telegram run.

### 0.8.1 final source-preservation review

Simple HTML tables must retain visible cell boundaries and row order independently
of source whitespace. Nested tables and spanning cells are unsupported and must
fail closed rather than imply ambiguous column relationships. Hidden tables and
cells must not corrupt surrounding visible row state.

Protection metadata must survive both selected highlights and independently
retained conditions. Section/exclusion-tagged field passages cannot disappear
because the model selects them. Navigation and incomplete-context holds remain.
Absent metadata preserves legacy behavior; supplied metadata must be parallel
lists of string lists, including rejecting an empty list for nonempty passages.
The running budget comparison stays frozen at its recorded commit; these final
corrections receive separate offline validation, not retroactive live credit.
